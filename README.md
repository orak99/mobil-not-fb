# Geri bildirimsiz deney önizlemesi

Mevcut mobil deneyden ayrı sürüm. Billboard gösteriminden sonra doğrudan sorular açılır. Geri bildirim sunumu, değerlik ve kaynak soruları kaldırılmıştır; son bölümde yalnızca partner hakkındaki açık uçlu soru bulunur.

Google/Apps Script bağlantısı yoktur. Yanıtlar yalnızca bu sürüme ait tarayıcı depolamasında, sayfa yenilendiğinde devam edebilmek için tutulur. Bu bir veri toplama yayını değildir.

`index.html`, `backdrop.jpg` ve `billboards/` birlikte yayımlanır. Orijinal deney dosyaları değiştirilmemiştir.
